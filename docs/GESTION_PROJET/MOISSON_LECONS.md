# Moisson mensuelle des leçons (protocole P04 §7)

## Rituel (1er du mois)
1. Lister les issues mergées du mois (label `lecon` à poser sur toute issue qui documente une leçon réutilisable).
2. Consolider les leçons dans `AGENTS.md` (règles actives) et archiver l'historique dans `docs/archive/AGENTS_HISTORIQUE_UTILE.md` quand AGENTS.md grossit (> 150 Ko cible).
3. Dédoublonner : une leçon déjà documentée = commentaire sur l'issue, pas de copie.
4. Publier un résumé « leçons du mois » en commentaire sur l'EPIC de pilotage.

## Label
`lecon` (couleur 1D76DB) — posé par le moissonneur sur les issues sources.
